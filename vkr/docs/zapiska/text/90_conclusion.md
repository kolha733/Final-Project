# ЗАКЛЮЧЕНИЕ

В работе разработан фреймворк scendrift для генерации бенчмарков систем выявления концептуального дрейфа с автоматизированным формированием и параметризацией сценариев. Цель работы достигнута, поставленные задачи решены.

1. Проанализированы виды концептуального дрейфа, методы его обнаружения, существующие средства генерации потоков и оценки детекторов (MOA и CD-MOA, scikit-multiflow, river, CapyMOA, stream-learn, Frouros, Menelaus, генератор Петижана–Уэбба) и исследовательские бенчмарки. Выявлены пять пробелов: нет общей семантики величины дрейфа, сценарий не является проверяемым объектом, наборы сценариев формируются вручную, перебором или случайно, генерация, метрики и статистика разнесены по разным инструментам, области отказа детекторов изучаются по одному параметру.
2. Построена формальная модель сценария дрейфа $S = \langle B, E, \Omega, s \rangle$ с {{ model.constraints }} ограничениями допустимости и {{ model.warnings }} предупреждениями. Введена единая шкала величины дрейфа — расстояние полной вариации между совместными распределениями; для калиброванного семейства получены точные выражения величины реального, виртуального и априорного дрейфа, калибровка реального дрейфа с учётом дисбаланса и доли затронутых признаков и ограничения достижимости величины. Утверждения модели подтверждены методом Монте-Карло.
3. Спроектирована архитектура фреймворка из шести подпакетов и декларативный формат сценария (YAML, JSON Schema) с канонической и компактной формами, наследованием шаблонов и идентификацией по содержимому.
4. Реализованы генераторы потоков трёх групп семейств — калиброванного hyperplane_gauss, классических генераторов river и внедрения дрейфа в реальные данные — с автоматическим построением истинной разметки и фактической величины каждого события.
5. Реализован модуль автоматического формирования наборов сценариев: четыре плана эксперимента, три способа учёта ограничений (отклонение, проекция, условные домены), шаблоны, композиция из блоков, шкала сложности, манифест и проверка целостности. Доказано, что условные домены дают допустимые точки без атомов на границе.
6. Реализованы единый интерфейс девяти детекторов river и трёх базовых линий, векторная базовая модель, раннер с повторами, кэшем и параллельным запуском, метрики обнаружения, статистическое сравнение по Демшару и отчёты.
7. Проведено экспериментальное исследование. Генератор воспроизводит заданную величину дрейфа в пределах выборочной погрешности. На автоматически сформированном наборе средний F1 детекторов — от {{ e2.f1_min }} до {{ e2.f1_max }}, периодический сброс без анализа данных получает {{ e2.f1_periodic }}, но худший прирост accuracy. Главный фактор сложности — величина дрейфа на единой шкале; виртуальный дрейф по потоку ошибок на синтетических данных не обнаруживается; ручной набор классических потоков завышает качество и даёт иное ранжирование; ранжирования по F1 и по accuracy не связаны.

Научная новизна работы состоит в формальной модели сценария с проверяемыми ограничениями, единой аналитически калиброванной шкале величины дрейфа для трёх видов изменения, методе формирования наборов сценариев по планам эксперимента с условными доменами и методике описания областей отказа детекторов с поправкой на случайный уровень обнаружения.

Практическая значимость работы: фреймворк позволяет выбирать детектор под характеристики прикладной задачи, проверять новые детекторы на воспроизводимых наборах сценариев и избегать ошибок протокола оценки, выявленных в работе (влияние сброса модели на двусторонние детекторы, «иллюзия прогресса» периодического сброса, расширение окон допуска при широких переходах).

Ограничения работы: калиброванное синтетическое семейство одно (бинарная классификация, линейная граница, гауссовы признаки); ограничение достижимости величины — свойство выбранной параметризации; базовая модель одна, а детекторы сравниваются с параметрами по умолчанию; окно допуска фиксировано; числа экспериментального исследования получены в режиме {{ run.mode }}. {{ run.full_note }}

Направления развития: калиброванные семейства с нелинейной границей и многоклассовой разметкой; детекторы без учителя, отслеживающие распределение признаков, для которых виртуальный дрейф наблюдаем; подбор гиперпараметров детекторов под область пространства сценариев; окно допуска, зависящее от ширины перехода; уточнение шкалы сложности с упором на величину дрейфа.
